About the Developer

Vaibhav Sharma, a passionate web developer with a keen interest in creating dynamic and user-friendly web applications. This project is a testament to his skills in frontend development, asynchronous programming, and API integration.

How It Was Made

This application fetches real-time meteorological data using asynchronous JavaScript functions. The UI is built for responsiveness and speed.

Tech Stack
  • Frontend: HTML5, Custom CSS, Bootstrap 5
  • Logic: Vanilla JavaScript (ES6+), Fetch API
  • Backend: Vercel Serverless Functions (Node.js)
  • Data: OpenWeatherMap REST API
