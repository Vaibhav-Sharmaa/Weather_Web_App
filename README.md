# Weather App

A responsive, real-time weather dashboard built with vanilla JavaScript and Bootstrap 5. It fetches live meteorological data via the OpenWeatherMap REST API.

## Features
* **Live Weather Data:** Displays temperature, humidity, pressure, wind speed, and wind gusts.
* **City Search:** Query weather for any global city with built-in validation and 404 error handling for invalid inputs.
* **Comparison Table:** View pre-loaded weather data for multiple cities simultaneously.
* **Responsive UI:** Fully mobile-friendly layout utilizing Bootstrap 5 grid systems and modals.

## Tech Stack
* **Frontend:** HTML5, Custom CSS, Bootstrap 5
* **Logic:** Vanilla JavaScript (ES6+), Fetch API
* **Backend:** Node.js (Vercel Serverless Functions)
* **Data Provider:** OpenWeatherMap API
